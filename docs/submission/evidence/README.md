# Свидетельства и исходные числа

[Документация](../../README.md) · [История решений](../../EXPERIMENTS.md) · [Как читать результаты](../../RESULTS_GUIDE.md)

Это ограниченная публичная подборка. JSON-файлы служат проверке цифр и происхождения примеров; связный рассказ находится в руководствах выше.

| Файл | Содержание | Граница вывода |
|---|---|---|
| [История сравнений](DECISION_HISTORY.json) | Агрегаты query policies, контекста, агентов, reader и answer-fit; hashes research-источников | Новая публикация старых измерений, не новый прогон; полных исследовательских данных здесь нет |
| [Sol и Astra](SOL_READER_COMPARISON.json) | Reader-контроль, повторы, задержки и usage | Авторские известные случаи, не benchmark произвольных документов |
| [Sol через API](SOL_HTTP_SUMMARY.json) | Исторические 12 HTTP-проверок Sol v1 | Одна попытка на вызов; не live-оценка retries v2 |
| [Переиспользование индекса](SOL_VECTOR_REUSE.json) | Сохранение прежних векторов при смене reader | Пять восстановленных документов и два новых учебных TXT |
| [Девять открытых ответов](SYNTHETIC_HTTP_OUTPUTS.json) | Точные синтетические ответы, цитаты и описание удаления служебных полей | Три real-TXT случая не публикуются |
| [Изменения v2](SUBMISSION_V2_CHANGES.json) | Отличия от Sol v1 | Инженерная доработка транспорта и упаковки |
| [Проверки v2](SUBMISSION_V2_VALIDATION.json) | CPU, Linux и публичная поставка | Model doubles / mock transport, не новое измерение качества AI |
| [Историческая инфраструктура](HISTORICAL_INFRASTRUCTURE.json) | Связи с прежними инфраструктурными проверками | Не повтор всех проверок на текущем reader |
| [Происхождение Luna-примеров](HISTORICAL_LUNA_EXAMPLES_METADATA.json) | Учёт прежней версии примеров | Не результаты текущего Sol |

`research_artifact` в истории сравнений обозначает путь в полном локальном исследовательском workspace. SHA-256 фиксирует использованный источник, но не заменяет доступ к нему. Gold, reviewer notes, полные traces, credentials и ledgers сюда не включены.

# Машинные сведения о поставке

[Документация](../README.md) · [Читательский итоговый отчёт](../FINAL_REPORT.md) · [Свидетельства и исходные числа](evidence/README.md)

Эта папка нужна для проверки точных версий. Для знакомства с проектом начните с [истории решений](../EXPERIMENTS.md).

| Файл | Назначение |
|---|---|
| [HANDOFF.json](HANDOFF.json) | Зафиксированное состояние передачи, выбранный профиль и его hash |
| [READINESS.json](READINESS.json) | Готовность на момент приёмки; в этой поставке совпадает с handoff |
| [SUBMISSION_PROFILE.json](SUBMISSION_PROFILE.json) | Машинное описание выбранной конфигурации |
| [evidence/](evidence/README.md) | Исторические результаты, публичные ответы и агрегаты сравнений |

Это исторические manifests, а не текущая проверка доступности внешних моделей. Их поля не обновляются из-за редакционных изменений README. Действующие инструкции запуска — в [руководстве](../RUNNING.md).

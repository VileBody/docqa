# Документация DocQA

[← Главная проекта](../README.md)

DocQA отвечает по выбранному TXT-документу и возвращает проверяемые цитаты. Основной сервис использует один поисковый проход и Sol/P1. Выбору предшествовали сравнения запросов, контекста, агентных режимов и reader-моделей.

## Что означают названия

| Обозначение | Значение |
|---|---|
| **P0 / P1** | Версии инструкции reader; P1 включает шесть учебных демонстраций |
| **Flow** | Один маршрут поиска, ранжирования и ответа |
| **Raw** | Поиск по исходному вопросу без модельной переформулировки |
| **Pack** | Фрагменты источника, переданные reader |
| **Dev / reserved** | Набор для разработки / авторский отложенный набор |
| **H01–H12** | Идентификаторы исторических HTTP-проверок, не версии сервиса |
| **Submission v1 / v2** | Версии поставки; v2 добавляет ограниченные транспортные retries |
| **Sosana / Luna, Sol, Astra** | Названия вариантов внешнего провайдера; upstream не подтверждён |

`assets/` содержит рисунки и данные графиков. `submission/` хранит машинные manifests; начинать чтение с них не требуется. Имена файлов сохранены для стабильности ссылок из кода и прежних поставок, а смысловые названия вынесены в навигацию.
